# Runtime dependencies: what scoring a record and serving it over HTTP needs.
# Pinned to the versions this project is known to run on (Python 3.13.9, the
# interpreter the `venv` Jupyter kernel actually points at).
#
#     python -m venv .venv
#     .venv/Scripts/activate          # Windows;  source .venv/bin/activate on Linux/macOS
#     pip install -r requirements.txt
#
# NOTE: `python` on PATH may be a different interpreter with none of this
# installed - check `python -c "import sys; print(sys.executable)"` before
# blaming the code for a ModuleNotFoundError.
#
# **Training and the notebooks need `requirements-dev.txt` instead**, which
# installs this file plus xgboost, matplotlib, seaborn and Jupyter. The split is
# not cosmetic: a deployment installs *this* list into a size-capped function
# bundle, and the dev extras are ~230MB of it. It also matches the rule
# `Src/__init__.py` already follows - scoring must not drag in a training
# dependency.
